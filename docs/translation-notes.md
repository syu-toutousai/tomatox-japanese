# 訳語の選び方

## 基本

- 画面の枠組みと操作は日本語にする。
- 漢語を重ねるより、動詞や和語で言い換える。
- ただし、日本語として定着している語（設定、再生、字幕、著作権など）は無理に変えない。
- 作品名・ジャンル・出演者・あらすじなど、配信元から来る内容は翻訳しない。

## 内部 ID を残した理由

TOMATOX は既定の動画ソースを `默认`、候補を `量子资源` という ID で
IndexedDB と localStorage に保存している。ID を変えると、既存の利用者データと
一致しなくなり、設定画面のチェックや検索の分岐が壊れる。

そのため、保存する値はそのままにし、設定画面で `id` を表示する箇所だけを
`はじめから` / `量子資源` に置き換えている。

## xgplayer

TOMATOX は再生に xgplayer を使っている。`lang` を `jp` に切り替え、
同梱の日本語辞書の値を次のように言い換えた。

- プレイ → ながす
- 一時停止 → とめる
- ダウンロード → とっておく
- フルスクリーン → 画面いっぱいにする
- ミニプレーヤー → 小窓プレーヤー
- スクリーンショット → 画面を写す
- 生放送 → ライブ

エラー表示の HTML に直接書かれている中国語（「请刷新试试」など）も、
同じ調子の日本語に置き換えている。

## 確認

`node tests/test-mapping.js` で対応表の形を検査する。
`tools/verify-ja.py` で実際の画面を起動して、メニュー・設定・このアプリについての
ことばを検査する。ネットから来る作品名は中国語のままなので、検査対象は
画面の枠組みのことばに限っている。
